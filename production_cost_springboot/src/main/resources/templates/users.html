User Security & Account Provisioning

Create new staff and manager accounts with initial passwords requiring first-time reset.

First-Time Password Change Protocol

When you create a new user account with an initial temporary password, the system sets must_change_password = true. Upon their first login, they will be required to define their permanent password before accessing the system.
